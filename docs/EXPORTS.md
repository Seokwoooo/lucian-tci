# 로컬 결과 내보내기

`src/lib/export.ts`는 답변 문항을 받지 않고 채점 결과, 해석, 사용자가 고른 범위만 받습니다. 모든 파일은 현재 브라우저에서 생성하며, 파일 생성이나 다운로드를 위해 점수·답변을 서버에 보내지 않습니다.

## 선택 범위

```ts
interface ExportSelection {
  includeSummary: boolean;
  domains: DomainCode[];
  includeSubscales: boolean;
}
```

- 최초 UI 선택은 빈 상태로 둡니다. 영역이 하나도 없으면 모든 내보내기 함수가 오류를 반환합니다.
- `domains`에 있는 영역의 평균만 포함합니다. 중복 선택은 한 번으로 처리하며 존재하지 않거나 유효하지 않은 점수는 거부합니다.
- `includeSummary`가 참일 때만 선택 영역에 속하는 해석을 포함합니다. 텍스트·PDF는 중간점 3에서 가장 먼 해석을 최대 3개, PNG는 그중 1개를 보여 줍니다. 3에 가까운 해석도 그대로 허용하며 균형이나 정상 범위로 바꾸지 않습니다.
- ST 영역을 고르지 않으면 ST4·ST5의 정치·종교·성 고정관념 관련 개인 해석이나 점수가 들어가지 않습니다. 영역 선택은 공유할 수 있는 정보의 범위이므로 UI에서 항목을 분명하게 보여 줍니다.
- `includeSubscales`는 **PDF에서만** 적용합니다. 선택 영역의 하위척도 합계·문항 수·평균을 포함합니다. 7개 영역을 모두 고르고 상세 점수도 선택하면 30개가 포함됩니다. 텍스트·PNG에는 상세 점수표를 넣지 않습니다.

## 함수

`buildSummaryText(result, insights, selection, siteUrl?)`는 선택한 내용과 짧은 비공식 안내를 문자열로 반환합니다. 이 함수가 자동으로 클립보드·공유 앱·네트워크에 쓰지는 않습니다.

`renderShareImage(...)`는 **1080×1350px(4:5)** canvas를 반환합니다. 크림색 종이와 일곱 색의 잎 모티프, 큰 ‘내 마음의 결’ 제목으로 구성합니다. 선택한 영역 1~7개의 평균을 1–5 막대와 숫자로 모두 표시하며, 평균은 규준이나 백분위가 아님을 명시합니다.

PNG 요약은 동의한 경우에만 가장 두드러진 선택 하위척도 하나를 보여 줍니다. 메타데이터의 낮은/높은 응답 방향과 주의 문구를 사용하고, 근거 코드와 평균을 함께 표시합니다. 중간 응답은 문항별 응답이 섞일 수 있음을 설명합니다. 설명은 실제 글꼴로 줄바꿈하고 22~28px 범위에서 크기를 조정해 고정 카드 안에 보존합니다. 공간에 들어가지 않는 임의의 긴 설명·주소는 잘라내지 않고 오류를 반환합니다. 유형명, 백분위, 다른 사람의 참여 수를 만들지 않습니다.

`downloadPng(...)`는 위 canvas에서 PNG를 만들어 다운로드합니다. `downloadPdf(...)`는 jsPDF를 필요한 순간에만 불러와 A4 여러 페이지를 만듭니다. PDF는 선택 영역 설명·낮은/높은 응답 방향·주의점과 선택한 상세 점수를 보존합니다. 줄마다 남은 공간을 확인해 다음 페이지로 넘기며 한글을 바이트 단위로 자르지 않습니다.

기본 사이트 주소는 `https://lucianlabs.dev/tci/`입니다. 배포 주소가 다르면 마지막 인자로 지정합니다. 주소의 쿼리와 fragment는 제거하며 `http`·`https`만 허용합니다. 생성한 파일의 사이트 주소에는 결과를 붙이지 않습니다. 다운로드는 blob URL을 가리키는 임시 로컬 링크로 시작하고, 링크를 바로 제거하고 blob URL을 30초 후 해제합니다.

## 글꼴과 PDF 제약

UI는 `@fontsource/noto-sans-kr`의 OFL 글꼴을 이 버전의 한국어 문구에 맞춰 부분집합으로 만들고, `src/fonts.css`에서 `public/fonts/noto-kr-{400,600}.woff2`를 같은 origin의 자산으로 제공합니다. 재생성 스크립트는 `scripts/subset-fonts.py`이며 글꼴 라이선스도 함께 보존합니다. 내보내기는 실제 출력할 한글을 `document.fonts.load`에 전달해 두 굵기의 Unicode 부분 글꼴이 모두 준비되기를 기다립니다. 글꼴이 없거나 15초 안에 준비되지 않으면 오류로 중단합니다. 외부 폰트 서비스나 수동 네트워크 요청은 사용하지 않습니다.

PDF는 한국어 글꼴 임베딩 대신 canvas 페이지를 이미지로 넣습니다. **텍스트 검색·선택·스크린리더 읽기가 지원되지 않습니다.** 이 제약은 PDF 본문에 표시하며 접근 가능한 읽기는 웹 결과 화면이나 선택한 텍스트 요약을 사용합니다. 자동 테스트만으로 글자의 실제 모양·가독성을 보장하지 않으므로 브라우저에서 만든 PNG와 PDF를 직접 열어 확인합니다.

## 확인

```sh
npm test -- tests/export.test.ts
```

단위 테스트는 선택 범위, 해석 상한, 민감 해석 제외, 빈 선택 거부, 상세 점수의 PDF 한정, 안전한 사이트 링크, 글꼴 실패와 실제 출력 텍스트 로딩을 검증합니다. 실제 브라우저에서는 기본·모든 영역·상세 PDF를 각각 저장해 파일 형식, 여러 페이지, 한글, 페이지 경계와 선택하지 않은 내용의 부재를 확인합니다.
