# 무료 TCI 기질검사 설계

사용자가 승인한 상세 요청(2026-10-16)을 구현하는 독립 정적 서비스다. 기존 사이트의 변경 파일을 건드리지 않는다.

- 원본: 공식 IPIP key/table HTML 스냅숏에서 289개 문항 위치, 30개 하위척도, 7개 영역을 추출한다. 중복 문장도 위치 ID를 따로 보존한다. ST3는 없다.
- 응답: 5점, 한 문항씩. ID 기반 저장, 즉시 저장, 이전/다음, 키보드, 최종 답변 검토, 삭제 확인. localStorage 실패는 명시한다.
- 채점: 역채점 6-r, 하위척도 합/평균, 영역은 하위척도 평균의 단순평균. 규준·백분위·진단은 없다.
- 해석: 실제 IPIP 하위척도 내용을 바탕으로 중립값 3 주변의 기술적 문구를 선택한다. ST4/ST5의 문화·정치·성 고정관념 한계를 별도로 안내한다.
- 디자인: 따뜻한 종이 배경, 짙은 올리브 텍스트, 식물의 잎을 연상시키는 7색 도형. 읽기 쉬운 한국어, 한눈에 보이는 단일 시작 버튼. lucian-uxui 요소의 필요한 패턴만 React로 이식한다.
- 개인정보: 답변/점수 전송 없음, 추적 없음, 외부 폰트 없음. 공유는 선택한 요약/영역만 명시적으로 처리. 일반 링크는 사이트 링크로 점수를 담지 않는다.
- 내보내기: 브라우저 canvas PNG, canvas 기반 PDF(한국어 모양 보존, 텍스트 검색 불가를 안내). PDF에는 선택한 요약과 영역/하위척도 포함 가능.
- 한계: 자동 테스트는 인간 사용성·번역 타당도 검증이 아니다. 초기에는 임의의 완료 시간을 표시하지 않으며 유효한 첫 응답 기록 10개 이상이 쌓인 뒤 개인의 응답 속도로 남은 시간을 추정한다.
- 배포: 독립 GitHub 공개 저장소는 사용자 요청으로 생성한다. 기존 운영 설정/DNS/프로젝트는 승인 없이 덮어쓰지 않는다. 안전한 독립 배포를 먼저 검토한다.

## 공유를 중심으로 한 표현 보완 · 2026-10-17

사용자가 요청한 Sites의 presentation-led 디자인·로컬 미리보기 지침을 적용했다. 따뜻한 종이 질감의 첫 화면에서 검사 시작과 결과 카드 예시로 이어지고, 결과에서는 사용자가 고른 내용만 한 장으로 담는 흐름이다. 예시는 모든 289문항에 3을 넣은 실제 채점 출력이며 합성 예시임을 밝힌다. 실제 사람의 결과, 평균, 참여 수로 표현하지 않는다.

PNG는 1080×1350의 4:5 크기다. 선택한 1~7개 영역의 평균, 동의한 경우 가장 두드러진 하위척도 하나의 기술적 설명, 근거 코드, 비공식 고지와 사이트 주소를 담는다. 공유 모달은 영역을 바꿀 때마다 로컬에서 이미지를 만들며, 이전 선택의 이미지는 즉시 숨긴다. 임의 성격 유형, 친구 비교·순위, 가짜 후기·참여 수는 사용하지 않는다. 방문자를 재촉하는 카운트다운과 강제 공유도 없다.
