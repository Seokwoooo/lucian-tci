# Lucian TCI · 무료 TCI 기질검사

공식 IPIP가 공개한 289개 예비 문항을 독립적으로 한국어로 번역한, 브라우저 안에서 사용하는 자기이해 도구입니다. 한 문항씩 응답하고 16가지 기질 캐릭터, 7개 영역, 30개 하위척도를 살펴볼 수 있습니다.

**정식 TCI-RS 검사가 아닙니다.** 공식 한국어 TCI 문항·매뉴얼·규준을 사용하지 않으며, 임상 진단이나 전문가의 심리평가를 대체하지 않습니다. 한국어 번역의 심리측정 타당성, 한국인 규준, 사람 대상 사용성·소요시간 검증은 아직 수행하지 않았습니다. 이름과 상표 사용의 국내 검토도 남아 있습니다.

- 공개 서비스: [lucianlabs.dev/tci/](https://lucianlabs.dev/tci/)
- MIT 공개 저장소: [Seokwoooo/lucian-tci](https://github.com/Seokwoooo/lucian-tci)
- 로컬 실행: `http://127.0.0.1:4173/tci/`

## 제공하는 기능

- **첫 화면:** ‘보통은 유료 검사 → 여기선 ₩0’, 흔한 3분 테스트·정식 TCI 검사·이 검사 비교표, 289문항 끝에 받는 것 6가지, 16가지 캐릭터 도감.
- **검사:** 같은 영역이 연달아 나오지 않게 섞은 고정 순서, 누르면 바로 다음 문항, 키보드 1–5·←·→, 7개 파트와 파트마다 흐린 캐릭터 실루엣·중간 단서, 답변 목록·수정.
- **저장:** 문항 ID 기반 자동 저장, 새로고침·다시 방문 시 이어 하기, 저장소 손상·차단 안내, 확인 후 삭제. 이전 v1 저장은 자동으로 옮깁니다.
- **채점:** 정·역채점, 30개 하위척도 합계·평균, 하위척도 평균을 동일 가중한 7개 영역 참고값. 규준·백분위·진단·직업 추천·궁합을 만들지 않습니다.
- **결과:** 16가지 기질 캐릭터 별명(NS·HA·RD·P가 3보다 높은지의 조합)과 점수로 그린 캐릭터, 손으로 돌려 뒷면 스탯을 보는 카드, 성격 무기, 4가지 기질 조합, 3가지 성격 영역, 반전 포인트, 가장 뚜렷한 세부 성향, 30개 세부 결과, 정반대·닮은꼴 캐릭터.
- **공유:** 피드 4:5·스토리 9:16 카드 이미지(점수 끄기 가능), 지원 기기의 이미지 바로 공유, X, 요약 복사, 전체 리포트 PDF, 친구 비교 링크.
- **링크 미리보기:** 캐릭터별 정적 페이지 `/tci/t/<캐릭터>/`와 1200×630 미리보기 이미지. 캐릭터 링크에는 점수가 없고, 비교 링크만 `#vs=` 뒤에 7개 영역 참고값을 담습니다.
- 자체 호스팅한 한국어 글꼴(400·600·800), 모바일 화면, 키보드 탐색, 움직임 줄이기 설정 반영.

16가지 캐릭터는 Lucian Labs가 점수 방향에 붙인 별명이며 검증된 심리학 유형이나 정식 TCI 분류가 아닙니다. 첫 화면의 ‘약 25~35분’은 289문항 × 문항당 5~7초로 계산한 값이며 사람을 대상으로 잰 시간이 아닙니다. 검사 중에는 실제 응답 시간이 10개 이상 쌓이면 남은 시간을 다시 추정합니다.

카카오 JavaScript SDK는 활성화하지 않았습니다. 지원 기기의 공유 메뉴에서 카카오톡을 고를 수 있는 경우만 있습니다.

## 실행과 검증

Node.js와 npm이 필요합니다. 설치 버전의 상세 조건은 `package-lock.json`과 각 패키지의 `engines`를 따릅니다.

```sh
npm ci
npm run dev
```

개발 서버와 미리보기의 포트는 4173이며 `/tci/`에서 실행합니다.

```sh
npm run validate:data
node scripts/validate-data.mjs --self-test
npm test
npm run build
npm run preview
```

브라우저 검증에는 Playwright의 Chromium이 필요합니다.

```sh
npx playwright install chromium
npm run test:e2e
```

`npm run build`는 데이터·한글 글꼴 검증 → TypeScript 검사 → Vite 빌드 순서로 `dist/`를 만듭니다. 일반 빌드에 Python은 필요하지 않습니다. 글꼴을 다시 생성할 때만 `fonttools`, `brotli`가 설치된 Python으로 `scripts/subset-fonts.py`를 실행합니다. 이미 생성한 글꼴과 OFL 원문은 `public/fonts/`에 보관합니다.

## 화면 주소

| 주소 | 화면 |
| --- | --- |
| `/tci/` 또는 `/tci/#home` | 시작·이어 하기 |
| `/tci/#characters` | 16가지 캐릭터 도감 |
| `/tci/#guide` | 시작 전 안내 |
| `/tci/#test` | 한 문항씩 응답 |
| `/tci/#review` | 완료 축하·답변 확인과 문항 이동 |
| `/tci/#result` | 완료한 응답의 결과; 미완료이면 시작 화면 |
| `/tci/t/<캐릭터>/` | 캐릭터 소개(정적 페이지, 링크 미리보기 포함) |
| `/tci/t/<캐릭터>/#vs=1-…` | 친구 비교 링크: 친구 캐릭터와, 내 결과가 있으면 비교 |
| `/tci/#about`, `#scoring`, `#privacy` | 출처와 한계, 채점 설명, 개인정보 처리 안내 |

알 수 없는 주소는 시작 화면으로 처리합니다. 링크 미리보기 이미지는 개발 서버를 띄운 뒤 `node scripts/generate-og.mjs`로 다시 만듭니다.

## 데이터·채점·보관

원자료는 [공식 IPIP 문항 키](https://ipip.ori.org/newTCIKey.htm)와 [비교표](https://ipip.ori.org/newTCITable.htm)입니다. OpenScales는 차이를 확인하기 위한 참고 자료이며 문항·구현의 기준 원본으로 사용하지 않았습니다. 원문의 S1–S5를 보존하고 영역만 SD로 연결하며, 없는 ST3는 추가하지 않습니다.

정방향은 응답값, 역방향은 `6 − 응답값`입니다. 각 하위척도 평균을 구한 뒤 영역 안에서 같은 비중으로 평균합니다. 높은 값과 낮은 값에 우열을 부여하지 않습니다. S1은 책임감이 아닌 Satisfaction, HA4는 피로가 아닌 Low Self-Efficacy, ST4는 Conservatism, ST5는 시대적 한계가 있는 Femininity라는 원문 척도임을 설명합니다.

이름·이메일·생년월일을 받지 않습니다. 답변과 채점·설명·파일 생성은 현재 브라우저에서 처리하며, 분석·광고·외부 AI SDK가 없습니다. localStorage는 같은 브라우저·같은 origin 안의 저장소이며 계정 동기화가 아닙니다. 일반 접속 로그와 사용자가 누른 외부 공유는 별도로 구분합니다.

PDF 리포트는 canvas 이미지를 넣은 문서로 한국어 모양을 보존하지만 **텍스트 검색·선택과 스크린리더 읽기를 제공하지 않습니다.** 웹 결과 화면과 ‘결과 요약 복사’가 텍스트 대안입니다. 다운로드 파일과 외부에 보낸 내용은 브라우저 답변을 삭제해도 남습니다.
